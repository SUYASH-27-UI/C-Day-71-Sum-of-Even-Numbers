# C Day 71 - Sum of Even Numbers

This program takes multiple numbers from the user and calculates the sum of all even numbers.

## Example

For the numbers:

```text
10, 7, 20, 13, 8
```

The even numbers are:

```text
10, 20, 8
```

Their sum is:

```text
38
```

## Concepts Used

* `for` loop
* `if` statement
* Modulus `%` operator
* Variables
* `scanf()`
* `printf()`

## How It Works

The program takes numbers from the user one by one. It checks each number using `number % 2 == 0`. If the number is even, it is added to the `sum` variable.

## What I Learned

I learned how to check even numbers and calculate their sum using a `for` loop and an `if` statement.
